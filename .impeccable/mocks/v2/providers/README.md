# Provider marks

Monochrome vendor marks used by the providers room and ready for the app's model tiles.
Sources: @lobehub/icons-static-svg (AI vendors) and simple-icons, fetched and rasterised at build time;
each PNG is the mark's alpha channel as ink, so it takes the colour of whatever tile it sits on.
The marks remain the trademarks of their owners and are used here for identification only.
Vendors with no published mark (Venice, Inception, Aion Labs, Bria, Inworld) have no file: the sheet
draws a hollow tile for them.
