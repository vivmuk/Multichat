Filtering

Both /models.md and /models.json take the same query parameters.

ParameterMeaning
typetext, image, video, tts, music, asr, inpaint, upscale, embedding, decision
qFree text matched against ID, name, vendor and capabilities
capComma list, all must match: vision, reasoning, tools, web, code, schema, audio, video, xsearch, tee, e2ee, logprobs
privacyprivate (Venice-hosted) or anonymized (proxied to the provider)
providerVendor name, such as Google or Anthropic
max_priceCeiling in USD on the headline rate: input price per 1M tokens for text, the per-unit price otherwise
uncensored1 keeps only models Venice marks uncensored
sortnewest (default), price, price-desc, name, context
limitMaximum rows
 
# The five cheapest text models that see images and call tools
curl "/models.json?type=text&cap=vision,tools&sort=price&limit=5"

# Video models, cheapest first, as a Markdown table
curl "/models.md?type=video&sort=price"

# One model in full: every price, limits, policy ratings
curl /models/claude-fable-5-2.md

Venice API documentation

Cached copies of docs.venice.ai, refreshed hourly, so an agent that can reach this site can read the whole API reference from one origin. The originals stay authoritative.

MCP

The same catalogue as tools, over Streamable HTTP, with no authentication. It is read-only: nothing here can spend money or change state.

ToolWhat it returns
list_modelsModels with ID and price, filtered by type, capability, vendor, privacy or a price ceiling
get_modelOne model's full sheet
read_venice_docsAny Venice documentation page as Markdown, or the index of all pages

Claude Code

claude mcp add --transport http venice-catalog /mcp

Any MCP client

{
  "mcpServers": {
    "venice-catalog": { "type": "http", "url": "/mcp" }
  }
}

To call the Venice API itself through MCP, or to search the docs, Venice runs its own servers: see the Venice MCP guide.

What an agent should know

  • Read IDs at run time. Models are added and retired often. The list here is read from the Venice API and refreshed every five minutes.
  • Prices are exact. US dollars as Venice reports them, never rounded. Video rates come from Venice's pricing page; POST /video/quote gives the price of a specific job.
  • This site holds no key. Reading the catalogue needs none. Calling the Venice API needs the caller's own key from venice.ai/settings/api, or a wallet through x402.
  • Policy ratings are opinions with a basis. Likeness and NSFW ratings are curated by the site's author from provider policy. “Open” means not blocked, and “inferred” means derived from the privacy tier, not checked.
